# Научно-образовательный квест «Космическое Золотое Кольцо»

## Описание проекта

### Концепция
Интерактивное 3D-приложение в формате виртуального тур-квеста по объектам научной инфраструктуры Золотого кольца России. Игрок выступает в роли участника научной экспедиции, исследует локации, проходит испытания и собирает артефакты.

## Архитектура проекта

### Основные компоненты
* **Система управления персонажем**
  * Движок на основе `CharacterBody3D`
  * Инвентарь и система взаимодействия с объектами
  * Интерфейс игрока

* **Игровые механики**
  * Система квестов и испытаний
  * Система сбора артефактов
  * Мини-викторины на каждой локации
  * Система прогресса и очков

* **Локации**
  * Стартовая сцена (завязка сюжета)
  * Первая сцена с картой маршрута
  * Исследовательские локации
  * Финальная сцена

## Структура проекта

### Основные папки и файлы
* **FBX** — 3D-модели
* **img** — изображения и текстуры
* **res** — ресурсы игры
Файлы .tscn — сцены Godot
Файлы .gd — игровые скрипты

## Основные скрипты

### Ключевые файлы
* **game.gd** — основной игровой движок (хранит текущие параметры игры)
* **CharacterBody3D.gd** — управление персонажем
* **Area3D.gd** — взаимодействие с объектами
* **SceneController.gd** — управление сценами

## Как запустить проект

1. Клонировать репозиторий
2. Открыть проект в Godot Engine 4.1
3. Настроить пути к ресурсам
4. Запустить сцену `world.tscn`

## Особенности реализации

### Игровые механики
* **Система инвентаря** с поддержкой до 30 предметов
* **Интерактивные объекты** с подсказками
* **Голосовое сопровождение** (TTS-система)
* **Система достижений целей** и очков
* **Система передвижения по локацмяс (карта Золотого кольца)**
